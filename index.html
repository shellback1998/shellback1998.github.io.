Turing Observatory

Turing Observatory is a personal application operated by Scott Gaudet. It monitors the availability and resource usage of his own infrastructure, displays Kubernetes and cloud account summaries, and provides controls for registered development labs.

Email notifications

The optional Gmail integration sends infrastructure outage, recovery, and explicit delivery-test emails from the Google account authorized by the operator to configured recipients. It requests only the Gmail send permission (gmail.send). It does not request permission to read an inbox or delete email.

Private dashboard

This website contains public information about the application. The working dashboard is privately hosted and is not available through this website. This site has no login or operational controls.
